SAFEHANGAR - VS CODE STARTER PROJECT

Files:
- index.html: page structure
- styles.css: responsive styling
- script.js: navigation and demo interactions

HOW TO RUN:
1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension (Extensions icon, search "Live Server").
4. Right-click index.html and choose "Open with Live Server".

NEW FEATURES (from TECHNO_PO.pdf):
- Hazard Reports page: 14 hangar hazard/incident categories with example reports, severity, facility and location. High/Critical reports create a Safety Alert and update the alert counts.
- Hangar Directory page: 12 aircraft maintenance facilities in Metro Manila, Clark and Subic with region filters and search.

NOTES:
This is a front-end demonstration. Aircraft and inspection records are only kept in the current page session and are not stored in a database. The sample checklist is illustrative and is not an approved aircraft maintenance checklist. Do not use it for actual maintenance release or airworthiness decisions.
